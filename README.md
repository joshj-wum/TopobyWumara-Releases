# Topo by Wumara

Topography tools for Autodesk Revit: survey points, surfaces, point cloud tools, stringing and more.
Works with **Revit 2024** and **Revit 2026**.

## Download

**[Download the latest installer](https://github.com/joshj-wum/TopobyWumara-Releases/releases/latest)**
(get `TopoSetup-x.y.z.exe` under *Assets*).

## Install

1. Close Revit.
2. Run `TopoSetup-x.y.z.exe`. No administrator rights are needed.
3. Windows may show a blue **"Windows protected your PC"** box because the installer isn't code-signed yet.
   Click **More info**, then **Run anyway**.
4. Choose the Revit version(s) to install for and finish the wizard.
5. Start Revit. If asked whether to load the add-in, choose **Always Load**.
   You'll see a **Topo** tab on the ribbon.

## Getting help

In Revit: **Topo tab, Settings panel, Help Guide** has a searchable guide to every command.

## Updating

**Topo tab, Settings panel, Check for Updates** tells you when a newer version is available
and links to the download. Run the new installer over the top; your settings are kept.

## Uninstall

Windows **Settings, Apps, Installed apps**, find *Topo by Wumara* and uninstall.

## Requirements

- Windows 10/11, 64-bit
- Autodesk Revit 2024 or 2026
